# Web Calculator

A simple interactive calculator built using HTML, CSS, and vanilla JavaScript.

This project is my first step towards building a web-based calculator, with plans to integrate a Python backend using Flask in future versions.

## Version

**v0.1.0 | Frontend Prototype**

## Features

- Interactive calculator interface
- Number input
- Clear all (AC)
- Delete last character (DEL)
- Basic operator selection
- Dynamic display updates

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Structure

```text
web-calculator_v01/
│
├── index.html
├── style.css
└── script.js
```

## Running Locally

1. Clone this repository.
2. Open the `frontend` folder.
3. Open `index.html` in your browser.
4. Start using the calculator.

No Python environment or backend server is required for this prototype.
